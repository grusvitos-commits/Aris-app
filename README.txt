АРИС PWA 0.8

Загрузите файлы и папку icons в корень публичного GitHub-репозитория.
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
После публикации откройте https://USERNAME.github.io/REPOSITORY/ на Android в Chrome и выберите Установить приложение.

ВАЖНО: Перед переходом экспортируйте JSON-копию из старого ARIS 0.7.4 и восстановите ее в новой версии через Настройки.
Не загружайте на GitHub файлы личных заметок или резервные копии.
Сервис-воркер и установка PWA не работают при открытии index.html как file://.
Напоминания в фоне пока не гарантируются.
